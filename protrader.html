📲 IQ Option
🌉 Como montar a ponte (5 min, grátis)
A IQ não aceita chamada direta de sites. A ponte é um mini-servidor seu, grátis, na Cloudflare: só repassa os pedidos do ProTrader para a IQ e não guarda o token.
  1. Toque em 📋 Copiar código da ponte (aqui embaixo) — faça isso no ProTrader publicado.
  2. Abra dash.cloudflare.com e crie uma conta grátis (e-mail e senha).
  3. No menu, entre em Workers e Pages (ou Compute → Workers) → Criar → Criar Worker (modelo "Hello World") → nome protrader-iq → Implantar.
  4. Toque em Editar código, apague tudo, cole o código copiado e toque em Implantar.
  5. Copie o endereço que aparece (termina em .workers.dev), cole no campo ponte acima e toque em Salvar ponte.
Teste: abrindo o endereço da ponte no navegador aparece "Ponte ProTrader → IQ Option funcionando."
O token fica só neste aparelho: não vai para o código do site (que é público) nem para o backup. Stop, meta, limite do dia e "uma ordem por vez" valem também para a IQ.
